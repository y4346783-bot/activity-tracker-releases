# ActivityTracker のインストーラー

Windows 用アクティビティトラッカー ActivityTracker の配布用リポジトリです。ソースコードは置いていません。

- [Releases](../../releases/latest) から `ActivityTracker-Setup-<版>.exe` をダウンロードして実行してください（管理者権限は不要です）。
- インストール済みのアプリは、ここの最新の Release を 1 日に 1 回確認し、設定画面から更新できます。
- `.sha256` は、インストーラーが壊れていないかをアプリが確かめるためのファイルです。
